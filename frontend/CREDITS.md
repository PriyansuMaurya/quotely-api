# Credits

## Design inspiration

The visual direction — glassy card, soft gradient light, restrained motion and
large display serif — is inspired by [Wensity UI](https://ui.wensity.com/).

**No Wensity source code is included in this project.** Wensity publishes React
components built on Tailwind CSS and Motion; this is an original Svelte
implementation written from scratch. Their commercial licence prohibits
redistributing Pro source, including ported versions, in a public repository, so
nothing was copied, and the free MIT components were not needed for a project
this small.

If you want the actual components, use them in a React codebase under their
licence: <https://ui.wensity.com/license>.

## Built with

- [SvelteKit](https://svelte.dev/docs/kit) — application framework
- [Svelte 5](https://svelte.dev/docs/svelte/overview) — runes-based reactivity
- [Tailwind CSS v4](https://tailwindcss.com/) — styling
- [Vitest](https://vitest.dev/) and [Testing Library](https://testing-library.com/docs/svelte-testing-library/intro/) — unit and component tests
- [Playwright](https://playwright.dev/) — end-to-end smoke tests
